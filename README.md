# talk & cut

말로 찍고, 느낌대로 보정하는 네컷 사진 부스 — 웹 MVP.

인생네컷 같은 무인 포토부스 흐름(포즈 고민 → 촬영 → 보정 → 프레임 → 출력)을 음성 대화로 진행한다.
최종 목표는 QCS6490 보드 위 온디바이스 키오스크이고, 이 웹 MVP는 UX와 명령 스키마를 먼저 검증하기 위한 버전이다.
배경 조사는 [docs/research-life4cut.md](docs/research-life4cut.md) 참고.

## 기능

| 기능 | 내용 | 웹 MVP 구현 | 보드 버전에서 교체할 부분 |
| --- | --- | --- | --- |
| 포즈 추천 | 인원·분위기에 맞춰 4컷 포즈 플랜(자연스럽게 → 귀엽게 → 재밌게 → 다 같이), 뷰파인더에 가이드 실루엣 표시 | 규칙 기반 점수 + MediaPipe Pose로 인원 자동 감지·포즈 일치 판정 | NPU 포즈 모델 |
| 감성 보정 | “몽환적인 느낌으로”, “조금 더 따뜻하게” → 밝기·대비·채도·색온도·색조·페이드·비네팅·그레인 파라미터 조정. 오버레이가 아니라 픽셀 보정 | 감성 사전(15종) + 멀티턴 상대 조정, WebGL 셰이더 | 감성→파라미터를 온디바이스 LLM이 같은 JSON으로 출력, Adreno GPU 셰이더 |
| 음성 촬영 | “3초 뒤에 찍어”, “바로 찍어”, “두 번째 컷 다시 찍어”, “포즈 맞추면 찍어줘”(조건부 셔터) | Web Speech API(ko-KR) + 규칙 기반 의도 파서 | Silero VAD + SenseVoice |
| 프레임 추천 | 보정된 사진의 평균 색·밝기, 현재 분위기, 인원수로 프레임 색과 모양(세로 네컷/2×2) 추천, 추천 이유 표시 | 색상 조화 규칙 | 동일 |

음성 명령 해석 결과는 오른쪽 메뉴의 “말하는 법” 탭에서 볼 수 있다. 한 발화에 여러 명령이 들어가면 순서대로 실행된다(예: “따뜻한 느낌으로 3초 뒤에 찍어줘” → `FILTER` 후 `CAPTURE`). 스키마는 [src/intent.js](src/intent.js) 상단 주석에 있다.

## 실행

카메라·마이크는 `localhost` 또는 HTTPS에서만 열린다. 빌드 과정은 없다.

```bash
npm start            # http://localhost:5173
# 또는
python3 -m http.server 5173
```

## 부스 사용법

1. **촬영 시작**을 누르고 카메라·마이크 권한을 허용한다. 카메라가 전체 화면에 표시되고 마이크가 자동으로 듣기 시작한다. 브라우저가 전체 화면을 허용하지 않으면 뷰포트 전체를 사용한다.
2. 화면에 표시된 포즈를 참고해 **“찍어줘”**(3초) 또는 **“바로 찍어”**라고 말한다. 카운트다운 중에는 **“촬영 취소”**라고 말할 수 있다.
3. 네 컷이 채워지면 결과 화면으로 넘어간다. **“다른 프레임”**, **“두 번째 컷 다시 찍어”**, **“저장해줘”**로 프레임 변경, 재촬영, PNG 저장을 할 수 있다. **“홈으로”**라고 말하면 카메라와 마이크를 닫고 시작 화면으로 돌아간다.

- 오른쪽 **메뉴**를 열면 촬영·취소·재촬영·저장, 카메라·마이크 재연결, 포즈·보정·프레임 변경을 터치로 할 수 있다. 음성 명령과 같은 문장을 직접 입력할 수도 있다.
- 음성 인식은 Chrome이나 Edge처럼 Web Speech API를 지원하는 브라우저에서 사용한다. 마이크 권한이 없거나 음성 서비스에 연결할 수 없으면 메뉴의 터치 조작을 사용한다.
- 포즈 인식(MediaPipe)은 CDN에서 모델을 받아오므로 인터넷이 필요하다. 못 불러오면 인원을 직접 고르는 방식으로 동작한다.
- `http://localhost:5173/?debug=1` 로 열면 랜드마크(빨간 점 = 화면 밖으로 본 관절)와 사람별 판정 결과·손-코 거리(어깨너비 배수)가 뷰파인더에 겹쳐 보인다. 이 값을 보며 `src/pose.js`의 `TH` 임계값을 조정한다.

## 구조

```
index.html          화면 구성
styles.css          스타일
src/main.js         상태 관리, 촬영 흐름, UI 연결
src/intent.js       발화 → 명령 JSON
src/emotion.js      감성 표현 → 보정 파라미터, 보정 이유 설명
src/glfilter.js     WebGL 보정 셰이더
src/pose.js         포즈 라이브러리·추천·가이드 그리기·MediaPipe 판정
src/frames.js       프레임 테마·추천·네컷 합성
src/voice.js        음성 인식/음성 안내
tests/              음성 인식 상태·파서·포즈 판정 단위 테스트
docs/               인생네컷 조사
```
