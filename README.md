# talk & cut

말로 찍고, 느낌대로 보정하는 네컷 사진 부스 — 웹 MVP.

인생네컷 같은 무인 포토부스 흐름(포즈 고민 → 촬영 → 보정 → 프레임 → 출력)을 음성 대화로 진행한다.
최종 목표는 QCS6490 보드 위 온디바이스 키오스크이고, 이 웹 MVP는 UX와 명령 스키마를 먼저 검증하기 위한 버전이다.
배경 조사는 [docs/research-life4cut.md](docs/research-life4cut.md) 참고.

## 기능

| 기능 | 내용 | 웹 MVP 구현 | 보드 버전에서 교체할 부분 |
| --- | --- | --- | --- |
| 포즈 추천 | 인원·분위기에 맞춰 4컷 포즈 플랜(자연스럽게 → 귀엽게 → 재밌게 → 다 같이), 뷰파인더에 가이드 실루엣 표시 | 규칙 기반 점수 + MediaPipe Pose로 인원 자동 감지·포즈 일치 판정 | NPU 포즈 모델 |
| 감성 보정 | “몽환적인 느낌으로”, “조금 더 따뜻하게” → 밝기·대비·채도·색온도·색조·페이드·비네팅·그레인 파라미터 조정. 오버레이가 아니라 픽셀 보정 | 감성 사전(15종) + 멀티턴 상대 조정, WebGL 셰이더 | 감성→파라미터를 온디바이스 LLM이 같은 JSON으로 출력, Adreno GPU 셰이더 |
| 음성 촬영 | “3초 뒤에 찍어”, “바로 찍어”, “두 번째 컷 다시 찍어”, “포즈 맞추면 찍어줘”(조건부 셔터) | Web Speech API(ko-KR) + 규칙 기반 의도 파서 | Silero VAD + SenseVoice |
| 프레임 추천 | 보정된 사진의 평균 색·밝기, 현재 분위기, 인원수로 프레임 색과 모양(세로 네컷/2×2) 추천, 추천 이유 표시 | 색상 조화 규칙 | 동일 |

음성 명령 해석 결과는 “말하는 법” 탭의 JSON에서 볼 수 있다. 한 발화에 여러 명령이 들어가면 순서대로 실행된다(예: “따뜻한 느낌으로 3초 뒤에 찍어줘” → `FILTER` 후 `CAPTURE`). 스키마는 [src/intent.js](src/intent.js) 상단 주석에 있다.

## 실행

카메라·마이크는 `localhost` 또는 HTTPS에서만 열린다. 빌드 과정은 없다.

```bash
npm start            # http://localhost:5173
# 또는
python3 -m http.server 5173
```

- 음성 인식은 크롬/엣지에서 동작한다. 지원하지 않는 브라우저에서는 “말 대신 입력” 칸에 같은 문장을 쳐서 쓸 수 있다.
- 스페이스바로도 3초 촬영이 된다.
- 포즈 인식(MediaPipe)은 CDN에서 모델을 받아오므로 인터넷이 필요하다. 못 불러오면 인원을 직접 고르는 방식으로 동작한다.

## 테스트

npm test    # 음성 명령 파서·감성 해석 단위 테스트 (Node 18+)
